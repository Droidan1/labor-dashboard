A working click-through of the proposed Bin Dump surface: photograph a pallet tag, Claude reads the seven fields off it, you check and correct them, and the pallet is logged with a timestamp into a week-grouped log you can edit later.

Nothing is wired up. This is a static prototype in docs/ — a directory scripts/build.sh deliberately excludes, so it never reaches production. No API is called, no photo leaves the page, the "extraction" is canned. No app code has been changed.

2What gets read off the tag

Redrawn from the real tag. The layout has a trap in it: every value is right-aligned and printed one line above its own label, so a label and its value pair up diagonally, not across. The dotted lines show it. A prompt told to "read what is to the right of PO:" finds nothing on that line and shifts every field by one — which is why this is worth drawing rather than describing.

Field map
FieldRead fromType
The barcode is not the item number — it is PRM + the truck # + this pallet's index (PRM-10490-30, and the footer reads "Pallet 30 of 30"). That gives two free cross-checks: the truck # read off the tag should match the middle of the barcode, and a mismatch is worth flagging rather than silently accepting.
Every field stays editable before submit, and nothing is stored until you press it.
