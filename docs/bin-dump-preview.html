Bin Dump — page preview

A working click-through of the proposed Bin Dump surface: photograph a pallet tag, Claude reads the seven fields off it, you check and correct them, and the pallet is logged with a timestamp into a week-grouped log you can edit later.

Nothing is wired up. This is a static prototype in docs/ — a directory scripts/build.sh deliberately excludes, so it never reaches production. No API is called, no photo leaves the page, the "extraction" is canned. No app code has been changed.
