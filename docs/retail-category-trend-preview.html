Category Trend — panel preview

A working click-through of the proposed Category Trend panel for the Retail Summary page: pick L2 or L3, pick the bucket — day, week, month or quarter — and read every category's line across those buckets, with a period-over-period change strip underneath. Every control below is live.

Nothing is wired up, and no app code has been changed. This is a static prototype in docs/ — a directory scripts/build.sh deliberately excludes, so it never reaches production. The numbers are synthetic (seeded, so they are stable between reloads) — plausible shapes on real category names, not your sales. Read the layout and the behaviour, not the figures.
