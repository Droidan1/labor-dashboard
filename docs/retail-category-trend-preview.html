Category Trend — panel preview

A working click-through of the proposed Category Trend panel for the Retail Summary page: pick L2 or L3, pick the bucket — day, week, month or quarter — and read every category across those buckets, with a period-over-period change strip underneath. Every control below is live.

Vs is the default, and it is the chart card this app already draws. Same shape, same colours, same legend pills as the Sales Trend card on the dashboard: green for this period, amber for the one before, a soft fill under the current line. The x-axis runs inside the period — Sun to Sat for a week, the days of the month for a month — so it shows where the difference came from, not just that there was one. Underneath, the same comparison for every category; click any row to redraw the card for it alone.

Grid gives each category its own panel and its shape across the whole window. Table gives each one a row of every bucket. Trend overlays up to six as lines when you want to watch a few closely — six is a legibility ceiling on that view alone, never a limit on what you can see.

Every question below is answered and folded in. The one genuinely new thing since you last looked is Compare → To date, which charts the period you are in against the same span of the one before it.

Nothing is wired up, and no app code has been changed. This is a static prototype in docs/ — a directory scripts/build.sh deliberately excludes, so it never reaches production. The numbers are synthetic (seeded, so they are stable between reloads) — plausible shapes on real category names, not your sales. Read the layout and the behaviour, not the figures.
